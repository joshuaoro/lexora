# Specialist Verification Sheet — Objectives 1, 3, 4 and 5

**For the three reading specialists. Parts B and C are completed near the end
of testing, per child; Parts A and D at close-out, alongside the ISO/IEC 25010
questionnaire.**

Four of the proposal's six objectives end in a judgement by the reading
specialists — not by the application, and not by the researchers:

| Objective | What the specialist determines | Part |
|---|---|---|
| 1 | "the extent to which these features address the reading-access needs identified by the reading specialists" | A |
| 3 | "whether the generated word lists correspond to the words the learner most frequently misreads, as verified by a reading specialist" | B |
| 4 | "whether the difficulty level assigned by the system corresponds to the learner's current decoding level, as assessed by a reading specialist" | C |
| 5 | "the usefulness of the generated progress reports for reading intervention, as assessed by the reading specialists" | D |

(Objective 2 is the scoring review inside the application; Objective 6 is the
ISO questionnaire and the children's pictorial scale.)

> **To the researchers — before printing.**
>
> **Part C must be done blind.** The specialist records their own assessment of
> the child's decoding level *before* looking at the level LEXORA assigned. A
> specialist who sees "Level 3" first will tend to find a Level 3 reader.
>
> **Part B uses the evidence the app shows.** On each learner's page, under
> *Current practice list*, every word carries how often the system scored it as
> misread and — where the specialist has reviewed those recordings — how many of
> those misreads they confirmed and how many they overturned.
>
> Requires adviser and ethics-committee review, like the rest. Delete this box
> before printing.

## Part C — Objective 4: assigned level against assessed decoding level

**Blind.** Complete the "Specialist's assessment" columns *before* opening the
learner's page.

Assess the child's current decoding level with your usual method, using the
level descriptions LEXORA uses. The words in each level are listed in the
consultation brief, Appendix F, if you want to sample them.

| Level | What a learner reads at this level |
|---|---|
| 1 | Two-syllable words with open syllables (CV-CV, V-CV): *mama, aso* |
| 2 | A closed syllable or a vowel sequence: *bahay, lapis* |
| 3 | Three syllables: *kamatis, salamat* |
| 4 | Consonant clusters or complex codas: *plato, tren, bulaklak* |
| 5 | Four or more syllables: *kalabasa, paaralan* |

| Child | Specialist's assessment (level 1–5) | Basis (method, date) | Level LEXORA assigned | Same? | If not, which is higher? |
|---|---|---|---|---|---|
| L1 | | | | ☐ Yes ☐ No | ☐ LEXORA ☐ Specialist |
| L2 | | | | ☐ Yes ☐ No | ☐ LEXORA ☐ Specialist |
| L3 | | | | ☐ Yes ☐ No | ☐ LEXORA ☐ Specialist |
| L4 | | | | ☐ Yes ☐ No | ☐ LEXORA ☐ Specialist |
| L5 | | | | ☐ Yes ☐ No | ☐ LEXORA ☐ Specialist |

**Note whether the specialist set the level by hand at any time** (the learner
page's level control). A level a specialist set is not the system's assignment,
and saying so is what keeps this objective honest.

**Analysis.**

> Correspondence (%) = children whose assigned level matched the assessed level
> ÷ children assessed × 100

Report the direction of each mismatch too. A system that is always one level
higher is telling you something different from one that is scattered.
